# Craftory

Каталог модов, сборок, ресурспаков, шейдеров, плагинов и датапаков для Minecraft: Java Edition в духе Modrinth. Весь сайт — один файл `index.html` без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере. Удобнее через локальный сервер:

```sh
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Сайт можно выложить на любой статический хостинг: GitHub Pages, Netlify, Cloudflare Pages.

## Демо-аккаунты

| Логин   | Пароль      | Роль                                     |
|---------|-------------|------------------------------------------|
| `demo`  | `demo1234`  | игрок с подписками, коллекциями и уведомлениями |
| `admin` | `admin1234` | модератор, видит жалобы                  |

Можно зарегистрировать и свой аккаунт.

## Возможности

**Для игроков**
- Шесть разделов каталога с поиском по названию, описанию, тегам и автору.
- Фильтры по категориям, загрузчику или платформе, версии Minecraft, окружению и открытой лицензии. Состояние фильтров хранится в адресе страницы.
- Сортировка по релевантности, загрузкам, подписчикам, дате создания и обновления. Вид списком или плиткой, постраничный вывод.
- Страница проекта: описание в Markdown, галерея с просмотром, журнал изменений, таблица версий с фильтрами, совместимость, ссылки, авторы.
- Окно «Скачать» само подбирает файл под выбранную версию игры и загрузчик.
- Подписки на проекты с уведомлениями о новых версиях, коллекции (публичные и личные), жалобы модераторам.
- Профили пользователей, светлая и тёмная тема, мобильная вёрстка.

**Для авторов**
- Создание проекта: черновик, публикация в каталоге или доступ только по ссылке.
- Загрузка версий с настоящими файлами (до 100 МБ), каналы релиз, бета и альфа, загрузчики, версии игры, зависимости.
- Редактор описания с предпросмотром, иконка, галерея с обложкой, ссылки, участники с ролями.
- Панель автора: сводка, проекты, уведомления, подписки, коллекции и аналитика загрузок по дням.

**Для модераторов**
- Очередь жалоб, скрытие проекта из каталога и возврат, уведомления автору и заявителю.

## Как устроено

- Вся логика в браузере. Данные лежат в `localStorage`, загруженные файлы и картинки в IndexedDB. Каждый браузер видит только свои данные.
- Пароли хранятся как SHA-256 с солью. Для настоящего многопользовательского сайта нужен сервер с базой данных и API. Эта версия подходит как прототип и демонстрация интерфейса.
- У демо-проектов нет настоящих бинарников, поэтому вместо них скачивается текстовая заглушка. Файлы, которые вы загрузили сами, скачиваются как есть.
- Иконки и скриншоты демо-проектов генерируются в пиксельном стиле прямо в браузере.
- Сбросить сайт к исходным данным можно в «Настройки → Данные».
