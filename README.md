# Craftory

Каталог модов, сборок, ресурспаков, шейдеров, плагинов и датапаков для Minecraft: Java Edition в духе Modrinth. Это полноценное веб-приложение: сервер на Node.js с базой SQLite и одностраничный интерфейс. Данные общие для всех посетителей.

## Запуск

Нужен Node.js 22.13 или новее. Внешних зависимостей нет, `npm install` не нужен.

```sh
npm start
# откройте http://localhost:3000
```

При первом запуске сервер создаёт базу `data/craftory.db` и заполняет её демо-каталогом.

| Логин   | Пароль      | Роль                                            |
|---------|-------------|-------------------------------------------------|
| `demo`  | `demo1234`  | игрок с подписками, коллекциями и уведомлениями |
| `admin` | `admin1234` | модератор: жалобы, скрытие проектов, сброс сайта |

Другие команды:

```sh
npm run dev   # перезапуск сервера при изменении файлов
npm test      # тесты API
```

## Настройки

Все настройки задаются переменными окружения.

| Переменная       | По умолчанию | Что делает |
|------------------|--------------|------------|
| `PORT`           | `3000`       | порт сервера |
| `HOST`           | `0.0.0.0`    | адрес, на котором слушает сервер |
| `DATA_DIR`       | `./data`     | папка с базой и загруженными файлами |
| `SEED_DEMO`      | `1`          | `0` — пустой сайт без демо-каталога, только администратор |
| `ADMIN_USERNAME` | `admin`      | имя администратора, если `SEED_DEMO=0` |
| `ADMIN_PASSWORD` | `admin1234`  | пароль администратора при первом запуске |
| `DEMO_PASSWORD`  | `demo1234`   | пароль демо-пользователя |
| `TRUST_PROXY`    | `0`          | `1`, если сервер стоит за nginx или другим прокси: брать адрес клиента и протокол из заголовков `X-Forwarded-*` |
| `COOKIE_SECURE`  | авто         | `1` — cookie только по HTTPS, `0` — всегда без флага Secure |
| `LOG`            | `1`          | `0` отключает журнал запросов |

Для публичного сайта поменяйте пароль администратора, поставьте `SEED_DEMO=0` и включите HTTPS на прокси.

### Docker

```sh
docker build -t craftory .
docker run -p 3000:3000 -v craftory-data:/data -e ADMIN_PASSWORD=смените-меня craftory
```

## Возможности

**Для игроков**
- Шесть разделов каталога с поиском по названию, описанию, тегам и автору.
- Фильтры по категориям, загрузчику или платформе, версии Minecraft, окружению и открытой лицензии. Состояние фильтров хранится в адресе страницы.
- Страница проекта: описание в Markdown, галерея, журнал изменений, таблица версий, совместимость, ссылки и авторы.
- Окно «Скачать» само подбирает файл под версию игры и загрузчик.
- Подписки с уведомлениями о новых версиях, коллекции и жалобы модераторам.

**Для авторов**
- Черновик, публикация в каталоге или доступ только по ссылке.
- Загрузка версий с файлами до 100 МБ и прогрессом загрузки, каналы релиз, бета и альфа, зависимости.
- Иконка, галерея с обложкой, описание с предпросмотром, ссылки и участники с ролями.
- Панель автора с аналитикой скачиваний по дням.

**Для модераторов**
- Очередь жалоб, скрытие и возврат проектов, уведомления автору и заявителю, сброс сайта к демо-данным.

## Устройство

```
server.js          точка входа, чтение настроек
server/app.js      HTTP-сервер: API, загрузка и раздача файлов, статика
server/db.js       схема базы SQLite
server/auth.js     пароли, сессии, ограничение частоты запросов
server/seed.js     демо-каталог
public/            интерфейс: index.html, app.js, styles.css
public/shared.js   справочники, общие для сервера и браузера
test/              тесты API
```

**Безопасность**
- Пароли хранятся как хэш scrypt с солью.
- Сессия хранится в cookie с флагами HttpOnly и SameSite=Lax. В базе лежит только хэш токена.
- Каждое изменение проверяет права на сервере: редактировать проект могут только его участники, модерировать только администраторы.
- Изменяющие запросы требуют заголовок `X-Craftory` и проверяют `Origin`. Это защищает от подделки запросов с чужих сайтов.
- Вход и регистрация ограничены по частоте. Повторное скачивание одного файла с одного адреса считается раз в 10 минут.
- Загруженные картинки проверяются по содержимому: принимаются только PNG, JPEG, GIF и WebP. Файлы версий отдаются только как вложение.
- Страница отдаётся со строгой политикой CSP: скрипты только с самого сайта.

**Данные.** База SQLite и загруженные файлы лежат в `DATA_DIR`. Для резервной копии достаточно скопировать эту папку при остановленном сервере. Файлы, на которые больше ничего не ссылается, удаляются автоматически.

У демо-проектов нет настоящих файлов, поэтому вместо них скачивается текстовая заглушка. Файлы, которые загрузили пользователи, скачиваются как есть.
